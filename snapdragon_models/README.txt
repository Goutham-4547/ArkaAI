SNAPDRAGON MODEL PLUG-IN DIRECTORY
==================================

The main ArkaAI chat path uses Qualcomm GenieX on Snapdragon Windows ARM64.

You normally do not need to manually put model files here: INSTALL_AND_RUN.bat
and setup_models.py can pull the selected GenieX model assets.

For a custom model, use the environment variables described in
SNAPDRAGON_RUNTIME.md rather than changing app.py.
