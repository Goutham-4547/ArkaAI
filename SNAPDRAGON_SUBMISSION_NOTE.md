# ArkaAI — Snapdragon AI Lab Challenge Submission Package

This archive contains the complete ArkaAI source, installer, runtime integration, semantic-memory engine, documentation, and third-party notices.

## What is complete in the submission

- Desktop ArkaAI application source
- Adaptive AI backend interface
- Hardware-aware model selection
- Qualcomm GenieX Snapdragon path
- Qualcomm AI Hub model identifiers for text and vision
- Local semantic document/conversation embeddings
- Student profile, mistake/strength memory and quiz persistence
- Emotion-aware response layer
- PDF/PPTX/image ingestion
- Study Studio outputs
- Voice and video features (online-enhanced paths are allowed)
- One-click Windows bootstrap
- Syntax verification during setup
- Third-party notices and model provenance

## Important distribution detail

The competition source archive does **not** attempt to redistribute third-party neural-network weights or the Qualcomm runtime binary. `INSTALL_AND_RUN.bat` installs GenieX and fetches the selected AI Hub model bundles on first run. After setup, the main assistant runs locally on the Snapdragon device.

This is intentional: the code submission remains complete and reproducible while third-party runtime/model licensing and provenance remain explicit.
